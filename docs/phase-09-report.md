## Initial Anthropic implementation and privacy (historical)

Pi1.5.0 remains the application framework. Isolated RPC configuration selects `ollama-local`/OpenAI-compatible local API or `anthropic-cloud`/native `anthropic-messages`, with fixed official endpoint `https://api.anthropic.com`. `DEFAULT_PROVIDER`, `CLOUD_MODEL` and the server-side key change behavior without source edits. Child model identity/provider/base URL are validated against the selected configuration. Ambient cloud keys/proxies/user Pi configuration are excluded from local children. No implicit fallback; existing narrow tool policy and server-owned factual citations remain.

Cloud chat uses native Anthropic tool choice to invoke the same registered read-only retrieval tool once, then constrained evidence-ID selection validated by the server; it does not pass OpenAI grammar fields to Anthropic. Cloud advice removes local grammar/thinking fields and keeps the one-turn/no-tools budget. Six advice sections plus at most one length repair remain bounded. The compatibility normalizer for tiny local-model tool text is local-only. Legacy structured essay internals remain outside the advertised evidence-first cloud path.

Only selected cloud mode may transfer bounded retrieved sentences, current/relevant user conversation and instructions to Anthropic; local embeddings/SQL remain local. Keys stay in server environment, never frontend/config responses/model prompts. Missing selected key yields503 `cloud_key_missing` before chat/essay writes or process creation; readiness/UI expose the gap. Key presence is not a successful cloud connection. Cloud accounts/model access/pricing/quality remain unverified; this phase incurred no inference charges. The configurable default is legacy `claude-haiku-4-5-20251001`, not a claim of newest/best model. Pi initialized that custom native model with a synthetic key and **zero provider requests**, proving configuration resolution only.

Official references checked7 November2026: [Pi model configuration](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/models-configuration.md), installed Pi docs/source and SDK `maxRetries:0`; [Anthropic legacy model ID/status](https://platform.claude.com/docs/en/models/haiku-4-5/overview); [Ollama networking](https://docs.ollama.com/faq). No dependency/model download or speculative version upgrade.
