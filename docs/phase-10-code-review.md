# Phase10 boundary review

Direct source review during full-corpus ingestion; final execution results belong in phase-10-report.md. This is a bounded engineering review, not an independent security audit.

| Boundary | Observed implementation | Finding / verification limit |
| --- | --- | --- |
| Local inference | Settings validate approved local Ollama addresses/model IDs; Pi child environment strips ambient cloud credentials/proxies, uses a private home and offline settings. Narrow registered transcript tool; no default shell/filesystem/web tools. | Existing policy/protocol tests plus per-run actual provider/model/cleanup metadata. Cloud fixture tests never count as cloud/live quality. |
| Corpus ingestion | Complete pinned manifest + source byte hashes; advisory writer lock; one process,4-input batches; finite per-call/episode/run bounds. Episode publication is transactional, prior versions retained, fingerprints skip unchanged data. | Verify all active spans/digest/model/revision and repeat counts after completion. No normal database reset/outage. |
| Source paths | Manifest contains4 paths excluded by the former ASCII/hyphen-only scope regex. Scope is a bound SQL value, not a filesystem read or executable URL. | Shared canonical one-directory Unicode word/hyphen pattern now covers all303 paths while rejecting traversal, extra separators, URLs and whitespace. Source URLs stay pinned to the fixed GitHub origin/revision. Focused tests cover retrieval/chat/essay and links. |
| Saved records | Session/user ownership and immutable answer-source snapshots; artifact content is derived from an owned accepted assistant reply. | Before/after saved-record hashes and original nine-episode/chunk hashes are separate preservation proofs. Single-evaluator model is not production authentication/tenancy. |
| Artifact rendering | Markdown raw HTML disabled; nh3 allowlist; static server HTML; CSP blocks network/scripts/forms/navigation; opaque script-disabled iframe; safe parent original-source links. | Existing hostile fixture browser/contract cases and actual saved-artifact reopening. Not universal browser/security certification. |
| RPC / lifecycle | Strict framing and bounded input/output, finite tool/provider turns, fresh Pi histories, process-group cleanup, tool bridge closure, generation lease and idempotent identities. | Real local success metadata separate from fake-process timeout/cancel/disconnect tests on isolated DB resources. |
| Logging / privacy | Safe event metadata and default protocol projections; raw diagnostic opt-in is private. Phase10 commands capture actual stdout and stderr separately in ignored storage; reports use IDs/hashes/counts. | Retained older raw traces remain sensitive; no logs are staged/published. Exact configured secret-value scan is bounded, not universal assurance. |
| Session access | API already paginates25 by default; UI had no older-page control despite42 saved sessions. | Reproduced in actual browser, added Load older sessions with deduplication/retained page depth and draft-preserving behavior. Actual and42-row fixture checks are separate. |
| Corpus status | UI formerly hardcoded partial library even at303/303. | Reproduced with a fixture; label now depends on observed active/discovered counts. Index completeness is distinct from product/answer readiness. |
| Answer grounding | Server validates selected evidence IDs and renders exact stored quotes with owned citations. Current chat deliberately chooses one bounded excerpt. | Citation integrity alone does not prove requested meaning is complete, context is preserved, or a source supports a guarantee. Direct review must score those separately, including multi-part/synthesis/advice requests. |
| Essay quality | Server-owned verbatim facts/citations, Pi/local advice, deterministic length/format checks, explicit editorial and acceptance gate. | Model advice can still leak instructions, promise outcomes, repeat itself or miss the requested case. Raw/as-generated rubric and any manual edits must remain distinct. |

All existing UI design/layout/resizer/provider/export work is preserved. The Phase10 frontend changes are the older-session access fix and truthful corpus label; no UI library or provider switching behavior was introduced. Further findings from actual frozen scenarios are recorded separately, with first attempts retained.

Final measured findings:all12770 source spans/version/dimensions/digests pass;original saved-row hashes preserved;27 running backend/agent files match checkout. Explicit materialized term tsqueries/count/DF avoid repeated per-row conversion/counting;ranking-equivalence real-PG regression passes for four synthetic queries and all84 frozen retrieval requests complete. No statement timeout or JIT change. Source/source-path scopes stay bound SQL values. Advice prompt now excludes topic/history/constraints while server retrieval still uses topic;mock boundary test and one actual local rerun verify this narrow change. The1216-word rerun remains a full-rubric failure.

No newly found critical security/data-loss issue in this bounded review. High-impact semantic defects remain:unrelated quoted answers to unsupported requests,partial multi-part answers,retrieval misses and irrelevant/incomplete essay evidence. These block release;test coverage/ID validity does not resolve entailment. No ad hoc per-question keyword guard,claim autoapproval,cloud fallback or arbitrary source editing introduced. Failure/recovery tests use isolated PostgreSQL and mock inference processes;actual local success cleanup is separately recorded. Nonfatal dependency/connection warnings and missing initial bridge diagnostics remain explicit in known-issues.md.
